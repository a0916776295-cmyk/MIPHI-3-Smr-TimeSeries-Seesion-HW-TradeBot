# FinGolem Trading Bot

Telegram-бот - телеграм-бот для анализа временных рядов ативов и формирования торговых рекомендаций. 
Проект создан в рамках выполенения выполенения сессионного задания по дисциплине "Временные ряды" НИЯУ МИФИ.

### Основные возможности

- **Анализ котировок** - получение актуальных данных по акциям через на основе использования Yahoo Finance API
- **Машинное обучение** - использование 16+ моделей для максимальной точности прогнозов
- **Торговые рекомендации** - формирование стратегий BUY/SELL/HOLD с обоснованием
- **Визуализация** - генерация графиков с историческими данными и прогнозами
- **Тесты реальности** - проверка точности прогнозов на реальных данных
- **Логирование** - детальное отслеживание всех операций в текстовом формате

### Требования
- Python 3.8+
- Telegram Bot Token
- Интернет-соединение для получения данных Yahoo Finance

### Установка зависимостей
```bash
pip install -r requirements.txt

Для корректной работы бота требуется токен, который храниться в файле  `config_bot.py`
```

### Основные команды
- `/start` - Запуск бота и главное меню
- `/help` - Помощь по использованию
- `/about` - Информация о боте
- `/status` - Статус системы

### Интерактивное меню
- **Выбор актива** - из списка популярных тикеров или ввод собственного
- **Сумма инвестиций** - выбор суммы для анализа ($100-$1000+)
- **Период прогноза** - от 1 до 90 дней


### Модели машинного обучения

#### Статистические модели
- **ARIMA** - Авторегрессионная интегрированная модель скользящего среднего
- **SARIMA** - Сезонная ARIMA для учета сезонности
- **Prophet** - Модель Facebook для прогнозирования временных рядов

#### Модели машинного обучения
- **Ridge Regression** - Линейная регрессия с регуляризацией
- **Random Forest** - Ансамбль деревьев решений
- **XGBoost** - Экстремальный градиентный бустинг
- **CatBoost** - Градиентный бустинг от Yandex

#### Нейронные сети
- **LSTM** - Долгая краткосрочная память (базовая и оптимизированная)
- **GRU** - Управляемые рекуррентные блоки (базовая и оптимизированная)
- **Transformer** - Модель с механизмом внимания
- **Informer** - Эффективная модель для длинных последовательностей
- **Autoformer** - Автокорреляционный трансформер
- **FEDformer** - Трансформер с разложением Фурье
- **TFT** - Temporal Fusion Transformer

#### Ансамблевые методы
- **Ensemble** - Комбинирование лучших моделей

### Торговые рекомендации

Бот генерирует рекомендации в формате:
- **BUY** - Рекомендация к покупке
- **SELL** - Рекомендация к продаже  
- **HOLD** - Рекомендация держать позицию

Каждая рекомендация включает:
- Прогнозируемую цену
- Потенциальную прибыль/убыток
- Уровень уверенности
- Рекомендуемое количество акций
- Обоснование решения

### Тесты реальности (эксперементальная функция)
В настоящее время функция не реализована.
Идея функции состоит в том, чтобы после получения предсказания поведения цены для конкретного актива, 
сравнить полученное предсказание с ральнными катеровками, сформированными рынком на конечную дату выполненного прогноза.

### Визуализация

Бот создает графики:
- Исторические данные по ценам
- Прогнозы всех моделей
- Увеличенные графики для детального анализа
- Сравнительные диаграммы точности моделей

## Логирование

Вся активность записывается в файл `Log/bot_activity.txt`:
- Действия пользователей
- Работа бота
- Ошибки и исключения
- Производительность моделей
- Торговые операции
- Системные события
