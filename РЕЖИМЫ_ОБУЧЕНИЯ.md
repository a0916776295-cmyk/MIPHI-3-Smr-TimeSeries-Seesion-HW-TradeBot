# 🚀 КОНФИГУРАЦИЯ РЕЖИМОВ ОБУЧЕНИЯ

## Изменения в версии от 11.01.2026

**✅ ПОЛНЫЙ РЕЖИМ - теперь по умолчанию!**

### 🧠 Полный режим (по умолчанию)
- **Модели**: 16 различных моделей (ARIMA, SARIMA, Prophet, LSTM, GRU, Transformer, Informer, XGBoost, CatBoost и др.)
- **Время обучения**: 30 секунд - 2 минуты 
- **Точность**: Максимальная точность прогнозирования
- **Использование**: Всегда, для любых периодов прогнозирования

### ⚡ Быстрый режим (только при необходимости)
- **Модели**: 5 легких моделей (ARIMA, SARIMA, Ridge, RandomForest, XGBoost)
- **Время обучения**: 3-5 секунд
- **Точность**: Базовая точность прогнозирования
- **Использование**: Только при установке переменной окружения `FORCE_FAST_MODE=true`

## 🔧 Как включить быстрый режим (если нужно)

### В Windows PowerShell:
```powershell
$env:FORCE_FAST_MODE = "true"
python FinGolem.py
```

### В Windows CMD:
```cmd
set FORCE_FAST_MODE=true
python FinGolem.py
```

### В Linux/Mac:
```bash
export FORCE_FAST_MODE=true
python FinGolem.py
```

## 🛡️ Система Fallback

Если полный режим по какой-то причине не удается:
1. ⚠️ Система автоматически переключается на быстрый режим
2. 📱 Пользователь получает уведомление о переключении
3. ✅ Прогноз все равно создается, пусть и с меньшей точностью

## 📊 Преимущества полного режима

- **Ensemble модели**: Автоматическое создание комбинированных моделей
- **Нейронные сети**: LSTM, GRU, Transformer для сложных паттернов
- **Временные ряды**: Специализированные модели TFT, Autoformer, FEDformer
- **Валидация**: Комплексная проверка реалистичности прогнозов
- **Выбор лучшего**: Из 16+ вариантов выбирается оптимальный

## ⚡ Когда использовать быстрый режим

- 🧪 **Тестирование**: Быстрая проверка работоспособности системы
- 🔧 **Отладка**: Диагностика проблем без долгого ожидания
- ⏰ **Срочные случаи**: Когда нужен результат немедленно
- 💾 **Ограниченные ресурсы**: На слабых компьютерах

## 📈 Рекомендации

**Для максимальной точности**: Используйте полный режим (по умолчанию)
**Для скорости**: Установите `FORCE_FAST_MODE=true` только при необходимости
