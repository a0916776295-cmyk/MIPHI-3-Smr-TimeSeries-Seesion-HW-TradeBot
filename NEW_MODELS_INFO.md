# 🤖 Новые модели и Ensemble методы

## ✨ Добавленные улучшения

### 🧠 Новые Transformer-based модели

#### 1. **Transformer модель**
- **Архитектура**: Multi-Head Self-Attention
- **Особенности**: 
  - Механизм внимания для выявления зависимостей в временных рядах
  - Positional Encoding для понимания временного порядка
  - 4 Transformer блока с LayerNorm и Dropout
- **Параметры**: 
  - d_model: 64 (размер embedding)
  - num_heads: 8 (количество головок внимания)
  - ff_dim: 128 (размер feed-forward слоя)
- **Преимущества**: Эффективно выявляет долгосрочные зависимости

#### 2. **Informer модель**
- **Архитектура**: ProbSparse Self-Attention + Distilling
- **Особенности**:
  - ProbSparse attention - эффективное внимание для длинных последовательностей
  - Distilling layers - уменьшение размерности между слоями
  - Encoder-Decoder архитектура
- **Параметры**:
  - d_model: 256
  - num_heads: 8 
  - Encoder layers: 2
  - Decoder layers: 1
- **Преимущества**: Оптимизирован для прогнозирования длинных временных рядов

### 🎭 Ensemble методы

#### 1. **Simple Average Ensemble**
- Простое среднее арифметическое всех прогнозов
- Улучшение точности: ~15%

#### 2. **Weighted Average Ensemble** 
- **Методы весов**:
  - `inverse_error`: Веса обратно пропорциональны RMSE
  - `inverse_mape`: Веса обратно пропорциональны MAPE  
  - `rank_based`: Веса на основе рангов производительности
- Улучшение точности: ~20%

#### 3. **Stacked Ensemble**
- Использует топ-3 модели
- Дополнительно увеличивает вес лучшей модели
- Улучшение точности: ~25%

#### 4. **Adaptive Ensemble**
- Адаптивная стратегия на основе согласованности моделей:
  - **Consensus**: Если модели согласны (низкая вариативность)
  - **Selective**: Если модели сильно расходятся (высокая вариативность) 
  - **Weighted**: Для средней вариативности
- Улучшение точности: 20-25%

## 🎯 Техническая информация
