# 🧪 Тесты Торгового Бота

Этот каталог содержит тесты для торгового бота с функциями прогнозирования и тестирования реальности.

## 📋 Структура тестов

### Основные тестовые файлы

- **`test_main.py`** - Основные тесты функциональности бота
  - Тесты импорта модулей
  - Базовые тесты модуля reality_test
  - Тесты финансового модуля

- **`test_trading_strategy.py`** - Тесты торговых стратегий
  - Тесты расчета торговых стратегий
  - Тесты генерации рекомендаций
  - Тесты обработки различных сценариев данных

- **`test_reality.py`** - Тесты модуля тестирования реальности
  - Тесты создания и управления тестами реальности
  - Тесты статистики
  - Интеграционные тесты с несколькими пользователями

### Вспомогательные файлы

- **`conftest.py`** - Базовая конфигурация для тестов
- **`run_tests.py`** - Скрипт для запуска всех тестов
- **`README.md`** - Этот файл с документацией

## 🚀 Запуск тестов

### Запуск всех тестов
```bash
# Из корневой папки проекта
cd tests
python run_tests.py
```

### Запуск конкретного тестового файла
```bash
# Основные тесты
python test_main.py

# Тесты торговых стратегий  
python test_trading_strategy.py

# Тесты реальности
python test_reality.py
```

### Запуск с помощью unittest
```bash
# Запуск всех тестов
python -m unittest discover -s tests -p "test_*.py" -v

# Запуск конкретного теста
python -m unittest tests.test_main.TestBasicFunctionality.test_reality_test_module_import -v
```

## 📝 Добавление новых тестов

### Создание нового тестового файла
1. Создайте файл `test_новый_модуль.py`
2. Добавьте необходимые импорты:
```python
import unittest
import sys
import os
sys.path.insert(0, os.path.dirname(os.path.dirname(__file__)))
```
3. Создайте классы тестов наследующие от `unittest.TestCase`
4. Добавьте методы тестов начинающиеся с `test_`

### Пример теста
```python
class TestNewModule(unittest.TestCase):
    def setUp(self):
        """Подготовка к каждому тесту"""
        self.test_data = {...}
    
    def test_basic_functionality(self):
        """Описание теста"""
        result = some_function(self.test_data)
        self.assertEqual(result, expected_value)
    
    def tearDown(self):
        """Очистка после каждого теста"""
        pass
```

## 🚨 Часто встречающиеся проблемы

### ImportError
- Убедитесь что `sys.path` настроен правильно
- Проверьте наличие файлов `__init__.py`
- Убедитесь что все модули доступны

### Проблемы с API
- Некоторые тесты могут быть пропущены при отсутствии интернета
- Используйте мок-объекты для изоляции от внешних сервисов

### Проблемы с данными
- Тесты создают временные данные в папке `test_data/`
- Убедитесь в наличии прав на запись в файловую систему
