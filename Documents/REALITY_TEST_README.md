# 🧪 ИСПЫТАНИЕ РЕАЛЬНОСТЬЮ - Краткое руководство

## Что это такое?
Новый режим в FinGolem Bot, который позволяет проверить точность прогнозов на реальных данных.

## Как пользоваться?

### ШАГ 1: Создайте прогноз
1. 🔍 Выберите тикер (например, AAPL)
2. 💵 Установите сумму (например, 1000$)
3. 📅 Выберите горизонт (например, 10 дней)
4. 📈 Нажмите "Анализ"

### ШАГ 2: Активируйте тестирование
1. 🧪 Нажмите "Испытание реальностью"
2. 🔬 Выберите "Создать тест"
3. 📅 Выберите дату проверки (завтра или позже)

### ШАГ 3: Получите результаты
Когда наступит выбранная дата:
1. 🧪 Зайдите в "Испытание реальностью"
2. 📈 Нажмите "Выполнить готовые"
3. 📊 Получите детальный отчет с метриками

## Что показывает отчет?

### 📊 Основные метрики:
- **RMSE** - точность прогноза (чем меньше, тем лучше)
- **MAPE** - ошибка в процентах (< 10% = хорошо)
- **Точность направления** - правильность предсказания тренда

### 🎯 Оценка модели:
- 🟢 **ОТЛИЧНАЯ** - MAPE < 5%
- 🟡 **ХОРОШАЯ** - MAPE 5-10%
- 🟠 **СРЕДНЯЯ** - MAPE 10-20%
- 🔴 **НИЗКАЯ** - MAPE > 20%

## 💡 Советы:
- Выбирайте дату тестирования через 2-7 дней
- Сравнивайте результаты разных моделей
- Чем больше исторических данных, тем точнее прогноз

## 🔧 Дополнительные функции:
- 📊 **Статус тестов** - посмотреть активные тесты
- 🗑️ **Отменить тест** - удалить ненужный тест
- 📈 **Выполнить готовые** - проверить результаты

---
*Используйте "Испытание реальностью" для научной оценки качества прогнозов! 🚀*
