# 🧪 Испытание реальностью - Документация

## Описание функционала

Режим "Испытание реальностью" позволяет проверить точность прогнозов моделей на реальных исторических данных. После создания прогноза пользователь может установить дату для проверки, и бот автоматически сравнит прогноз с фактическими котировками.

## 🚀 Как использовать

### 1. Создание прогноза
1. Выберите тикер актива (например, AAPL)
2. Установите сумму инвестиций
3. Выберите горизонт прогноза
4. Нажмите "📈 Анализ" для создания прогноза

### 2. Активация режима тестирования
1. Нажмите кнопку "🧪 Испытание реальностью"
2. Выберите "🔬 Создать тест"
3. Выберите дату для проверки прогноза (должна быть в будущем)

### 3. Выполнение теста
Когда наступит указанная дата:
1. Перейдите в "🧪 Испытание реальностью"
2. Нажмите "📈 Выполнить готовые"
3. Бот автоматически:
   - Загрузит актуальные котировки
   - Сравнит их с прогнозом
   - Покажет детальные метрики точности

## 📊 Метрики оценки точности

### Основные метрики
- **RMSE** (Root Mean Square Error) - среднеквадратичная ошибка
- **MAPE** (Mean Absolute Percentage Error) - средняя абсолютная процентная ошибка
- **MAE** (Mean Absolute Error) - средняя абсолютная ошибка

### Дополнительные метрики
- **Точность ±5%** - процент прогнозов в пределах 5% от реального значения
- **Точность ±10%** - процент прогнозов в пределах 10% от реального значения
- **Точность направления** - правильность предсказания тренда (рост/падение)

## 🎯 Критерии оценки моделей

### По MAPE (чем меньше, тем лучше):
- **< 5%** - 🟢 ОТЛИЧНАЯ точность
- **5-10%** - 🟡 ХОРОШАЯ точность
- **10-20%** - 🟠 СРЕДНЯЯ точность
- **> 20%** - 🔴 НИЗКАЯ точность

### По точности направления:
- **> 70%** - ✅ Хорошо предсказывает тренд
- **50-70%** - ⚠️ Умеренно предсказывает тренд
- **< 50%** - ❌ Плохо предсказывает тренд

## 🔧 Структура данных

### Файлы результатов
Результаты сохраняются в папку `RealityTests/{TICKER}-{DATE}/`:
- `reality_test_results.json` - полные результаты теста
- Включает исходные данные, метрики и отчет

### JSON структура теста
```json
{
  "ticker": "AAPL",
  "target_date": "2026-01-15",
  "forecast": [150.0, 152.1, 149.8, ...],
  "forecast_dates": ["2026-01-08", "2026-01-09", ...],
  "amount": 1000,
  "model_name": "LSTM_OPT",
  "created_at": "2026-01-08 10:30:00"
}
```

## 💡 Практические советы

### Выбор даты тестирования
- Выбирайте дату через 3-7 дней для краткосрочных прогнозов
- Для долгосрочных прогнозов (>20 дней) можно выбрать дату через 1-2 недели
- Учитывайте выходные дни - данные могут быть доступны с задержкой

### Интерпретация результатов
- MAPE < 10% считается хорошим результатом для финансовых прогнозов
- Точность направления > 60% показывает, что модель улавливает тренды
- Сравнивайте результаты разных моделей для одного актива

### Оптимизация точности
- Используйте больше исторических данных для обучения
- Сравнивайте результаты разных моделей (LSTM, GRU, Autoformer и др.)
- Учитывайте волатильность актива при оценке результатов

## 🛠️ Технические детали

### Архитектура модуля
- `reality_test.py` - основная логика тестирования
- `MenuBot.py` - интерфейс пользователя
- `FinGolem.py` - интеграция с основным ботом

### Автоматическое выполнение
- При запуске бота проверяются готовые к выполнению тесты
- Пользователи получают уведомления о готовых тестах
- Результаты автоматически сохраняются в файлы

### Обработка ошибок
- Валидация дат (не ранее завтрашнего дня)
- Проверка доступности данных
- Обработка выходных дней и праздников
- Резервные механизмы поиска ближайших дат
